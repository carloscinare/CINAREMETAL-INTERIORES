# CINARÉ Metal & Interiores — Demo GitHub Pages

Site estático de demonstração, pronto para publicar gratuitamente no GitHub Pages.

## Publicar

1. No GitHub: **Settings → Pages**.
2. Em **Build and deployment**, escolher **Deploy from a branch**.
3. Selecionar a branch `main` e pasta `/ (root)`.
4. Guardar. O GitHub fornecerá o endereço público do site.

## Personalizar

- Substituir textos e projetos por trabalhos reais.
- Trocar `exemplo@cinare.pt` pelo contacto real.
- Adicionar fotografias numa pasta `images/`.
- Ligar um domínio próprio no GitHub Pages, se desejado.
